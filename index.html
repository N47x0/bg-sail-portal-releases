Install (about 5 minutes, once)

  1. Tap Download the app. If Chrome says the file might be harmful, tap Download anyway.
  2. When the download finishes, tap Open. (Or open My Files, then Downloads, and tap the file.)
  3. If the phone says it is "not allowed to install unknown apps from this source", tap Settings, turn on Allow from this source, then go back.
  4. Tap Install. If Google Play Protect asks, tap More details, then Install anyway. If the phone says the app was blocked by Auto Blocker, open Settings > Security and privacy > Auto Blocker, turn it off, and start again at step 2.
  5. Tap Open. The logger's setup screen appears. Tap each button that is not yet green:
    • Allow notifications
    • Let the logger run all the time
    • Let the logger update itself (turn on Allow from this source, then go back)
  6. Join the boat's instrument WiFi and follow the setup steps on the screen.

You only do this once. The app updates itself when the phone has internet. You never need to come back here, unless you set up a new phone.

Replacing a broken or lost logger phone

  1. On the new phone: turn on the battery protection (charge limit) in Settings > Battery, and do not set a screen lock.
  2. Install the app as above.
  3. Open the app, join the boat's WiFi, and run the setup steps.

The new phone starts recording on its own. Recordings that were only on the old phone are not on the new one; copies backed up from the old phone's Documents/bg-sail-portal folder are kept.

Something wrong?

Send a photo of the logger app's screen to the person who set it up for you.
